What is this?

PeerPages lets you share a web server running on your own machine — localhost:3000 — with anyone, over this GitHub Pages address. No proxy server, no account, nothing for the visitor to install.

Someone sent you a link? It needs a peer-id: the address must end with #npub1… Ask them to resend the full URL their agent printed.

Want to share your own localhost? Install the agent and run it — it prints a ready-to-share link back to this page: 

go install github.com/aliosmanmho/PeerPages/agent@latest
peerpages serve --target http://localhost:3000

How it works, the security model and the honest limits: github.com/aliosmanmho/PeerPages
